# TypeScript for Next.js — Learning Guide

**Live site:** https://laavanjan.github.io/ts-nextjs-guide/

A personal study guide built from real questions and doubts.
Covers everything you need before starting Next.js.

## Topics

1. Types & Variables
2. Functions — all 4 formats explained
3. Interfaces & Types
4. Generics
5. Unions & Narrowing (FetchState pattern)
6. Utility Types — Partial, Omit, Pick, ReturnType
7. Async & Promises — Next.js server component pattern
8. React Patterns — props, useState, useRef, events
9. keyof & typeof
10. Advanced Patterns — as const, type guards, template literals


## Files

- `index.html` — page structure and sidebar
- `style.css` — dark theme, typography, layout
- `content.js` — all 10 topic contents and quiz logic
- `app.js` — navigation, progress tracking, quiz interactions

Progress is saved to localStorage so you can pick up where you left off.
